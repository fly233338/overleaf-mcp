# @fly233338/overleaf-mcp

An MCP server that reads and edits Overleaf projects through the Overleaf Git
integration.

Configure a single project with `OVERLEAF_PROJECT_ID` and either
`OVERLEAF_GIT_TOKEN` or `OVERLEAF_GIT_TOKEN_FILE`, or use a `projects.json`
configuration file for multiple projects. The executable is `overleaf-mcp`.
